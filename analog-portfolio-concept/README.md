# Single-page portfolio concept

This folder is a preserved copy of Ethan Ku's personal website source rebuilt as one minimal page.

The page includes the original introduction, five roles, Yotonix link, portfolio presentation, résumé, biography, photo collage, education, design foundations, interests, Ideas placeholder, and all contact methods. Project descriptions and document viewers use compact disclosures to keep the full content available without making the page visually noisy.

The site uses plain HTML, CSS, and JavaScript and can be previewed with any static file server. Previous page URLs remain as redirects to the relevant section of the main page.
